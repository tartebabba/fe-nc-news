# Fakeddit

Fakeddit is a Reddit-inspired web application that allows users to interact with news articles through a front-end React app and a back-end server with a database. Users can sort and vote on articles, log in, and post or delete comments.

## Features

-  **Browse Articles**: Find articles by topic.
-  **Sort Articles**: Sort articles by date, number of comments, or votes.
-  **Vote on Articles**: Upvote or downvote articles.
-  **Comment on Articles**: Post a comment if logged in.
-  **Delete Comments**: Delete your own comments.

## Upcoming Features

-  **User Management**: Create comprehensive user management and login functionality.

## Installation

To get a local copy up and running, follow these steps:

### Prerequisites

Ensure you have the following installed:

-  Node.js v21.5.0 or higher

### Clone the Repository

1. Fork the repository on GitHub.
2. Clone the forked repository to your local machine:
    ```bash
    git clone https://github.com/tartebabba/fe-nc-news
    ```
3. Navigate to the project directory:
    ```bash
    cd nc-news
    ```
4. Open the project in your code editor:
    ```bash
    code .
    ```

### Install Dependencies

Install the necessary npm packages:
```bash
npm install
```

### Running the Application
To preview the app, run the development server:
```bash
npm run dev
```
